# Mi primera página web

## Descripción del proyecto

Este proyecto consiste en la creación de una página web como parte de las prácticas de la asignatura de Lenguajes de Marcas.

La página contiene diferentes apartados y ejercicios para aprender a utilizar HTML y CSS, incluyendo:

- Página principal con ejemplos de elementos HTML.
- Horario semanal de clase.
- Formulario HTML.
- Ejercicios de formato de texto, enlaces e imágenes.
- Ejercicios de listas, menús y bloques.
- Calculadora y juego de piedra, papel o tijera.

## Tecnologías utilizadas

- **HTML5:** para crear la estructura y el contenido de las páginas.
- **CSS3:** para diseñar y dar formato visual a las páginas web.
- **Visual Studio Code:** como editor de código.
-**JavaScript:** para añadir interactividad y funcionalidades, como la calculadora y el juego de piedra  papel o tijera.
